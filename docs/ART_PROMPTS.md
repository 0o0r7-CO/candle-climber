> Workflow (mirrors the owner's proven ARK-monopoly flow): locked concept →
> detailed English master prompt → N visual variants from an AI image engine →
> agent design review → winning direction feeds M2 (landing page, mascot, OG art).
> Shared DNA block is prepended to every variant prompt.

## 2. Evaluation criteria (agent review rubric)

1. **Platform DNA fidelity** — matches vibevibe.fun palette/toy language without copying IP
2. **Mascot originality** — "Wick" reads as our own character, not a vibe-viber clone
3. **Game readability** — instantly reads as "climb the candlestick chart"
4. **Production feasibility** — achievable in CSS/canvas at 60fps on mobile
5. **Marketing punch** — stops the scroll on an X timeline

Output: 1–5 per criterion per variant, weighted verdict, and which elements to
fold into the M2 build (landing page + death card + OG image).
